Laboratório prático criado a partir do **GitHub Skills** para aprender os fundamentos do GitHub Actions e entender como workflows automatizados são estruturados dentro de um repositório.

## Objetivo

Este repositório registra uma etapa do meu estudo de CI/CD. O foco não é representar uma aplicação de produção, e sim demonstrar familiaridade prática com a estrutura e o ciclo de execução do GitHub Actions.

## Conceitos praticados

- Estrutura de arquivos YAML em `.github/workflows/`
- Eventos que disparam workflows
- Jobs e steps
- Uso de actions reutilizáveis
- Execução de comandos em runners do GitHub
- Evolução incremental de uma automação
- Leitura e acompanhamento de execuções no Actions

## Estrutura do laboratório

```text
.github/
└── workflows/
    ├── 0-start-exercise.yml
    ├── 1-step.yml
    ├── 2-step.yml
    ├── 3-step.yml
    ├── 4-step.yml
    ├── 5-step.yml
    └── welcome.yml
```

Os arquivos numerados fazem parte da progressão didática do exercício e foram mantidos propositalmente para registrar as etapas de aprendizado.

## O que este repositório demonstra

Este laboratório serve como evidência de contato prático com automação de repositórios e fundamentos que depois são aplicados em projetos maiores, onde GitHub Actions executa testes, lint, builds e validações de containers.
